# Unit Outline — Evidence Base

**Skill file:** `plugins/skills/planning/unit-outline/SKILL.md`
**Category:** Planning

## What the skill does
Builds a high-level unit outline — overview, curriculum links, big ideas, essential questions, a week-by-week sequence table, and an assessment overview — as a deliberate first stage of unit planning, fetching curriculum content before asking planning questions and always requiring teacher confirmation before any full lesson-by-lesson expansion begins.

## Evidence base

### Sequencing learning
- **Publisher/author:** Australian Curriculum, Assessment and Reporting Authority (ACARA), V9 Australian Curriculum
- **Year:** Current resource, V9 (accessed 2026)
- **URL:** https://www.australiancurriculum.edu.au/resources/curriculum-leadership/eight-aspects-of-curriculum-planning/sequencing-learning
- **Australian source:** Yes
- **What it says:** Describes sequencing as organising what is taught, when, and in what order so knowledge and skills build logically; recommends developing a whole-school curriculum map as "the overarching school-based plan that teachers use when engaging in unit planning," addressing timetabling and yearly plans.
- **Relevance to this skill:** Directly supports the skill's "Sequence Overview" week-by-week table and its instruction to keep it "a map, not a lesson plan" — ACARA's own guidance describes exactly this kind of higher-level sequencing artefact as the appropriate first planning layer before lesson-level detail.

### Australian Professional Standards for Teachers — Standards 2 and 3
- **Publisher/author:** Australian Institute for Teaching and School Leadership (AITSL)
- **Year:** Standards current; accessed 2026
- **URL:** https://www.aitsl.edu.au/standards
- **Australian source:** Yes
- **What it says:** Standard 2.3 requires teachers to "use curriculum, assessment and reporting knowledge to design learning sequences and lesson plans"; Standard 3.2 requires planning, structuring and sequencing learning programs.
- **Relevance to this skill:** Provides the professional basis for the unit outline's core content requirements — curriculum links tied to codes and achievement descriptors, and an assessment overview built before lesson detail — which is what Standards 2.3 and 3.2 describe as the knowledge a teacher must demonstrate when designing a learning sequence.

### Backward Design (Understanding by Design, Wiggins & McTighe)
- **Publisher/author:** Western Michigan University Center for Teaching, Learning and Assessment, summarising Wiggins & McTighe (1998), *Understanding by Design*, ASCD
- **Year:** Original work 1998 (ASCD); summary page current
- **URL:** https://wmich.edu/x/teaching-learning/teaching-resources/backward-design
- **Australian source:** No (international, but UbD is one of the pedagogy frameworks the skill explicitly supports and gives specific guidance for)
- **What it says:** Backward design's three stages are (1) identify desired results, (2) determine acceptable evidence, (3) plan learning activities — assessment design is deliberately positioned *before* the activity sequence, not after.
- **Relevance to this skill:** This is the direct evidentiary basis for the skill's own UbD-specific guidance: "Position assessment design (Stage 2) before the sequence (Stage 3)." It also supports the general structure of the outline template, which places Big Ideas / Essential Questions and Assessment Overview ahead of the week-by-week Sequence Overview.

## How this evidence should sharpen the skill
1. **Name the evidence behind "get this right before going deeper."** The intro states "A good unit outline is the foundation everything else builds on. Get this right before going deeper" as an assertion. A brief grounding note — e.g. referencing that this mirrors backward design's insistence on fixing results and assessment evidence before activities — would make this validation-gate design choice traceable rather than presented as a stylistic preference, especially since the skill enforces it strictly ("Do not proceed to full lesson planning without explicit confirmation").
2. **Connect the Sequence Overview table's brevity instruction to ACARA's own guidance.** The line "Keep each cell brief — this is a map, not a lesson plan" is a good instruction but currently unsupported. Citing ACARA's "Sequencing learning" resource (which explicitly separates whole-school/unit-level curriculum maps from lesson-level planning) would justify why the outline stage should stay high-level rather than drift into lesson detail — a common failure mode this line is clearly trying to prevent.
3. **UbD-specific guidance is already strong — extend the same rigor to Explicit Teaching.** The framework-specific guidance section gives UbD a precise instructional edit ("Position assessment design (Stage 2) before the sequence (Stage 3)"), but the Explicit Teaching entry is comparatively thin ("Sequence should show a clear arc from modelled → guided → independent across the weeks"). Given how much Australian evidence exists for explicit teaching specifically (AERO, CESE — see the lesson-planner and slide-deck evidence files), consider citing AERO's explicit-instruction guidance directly in this bullet, the way UbD is effectively grounded in Wiggins & McTighe.
4. **Add a light caveat to the pedagogy-framework reflection prompt.** The skill correctly avoids "silently restructuring the plan" and instead offers a reflection — this is good practice, but the reflection language ("a UbD lens would strengthen the big ideas section") could note that not all frameworks are evidenced to the same degree (e.g. UbD's evidence is professional-consensus-based, while Explicit Teaching draws on stronger empirical backing) so a teacher weighing framework choice understands the differing evidentiary weight, not just the differing "fit."

## Caveats / contested evidence
As with Unit of Work, backward design/UbD is widely adopted professional practice rather than an experimentally validated intervention with effect-size evidence — its status differs from, say, cognitive load theory's controlled trials cited in the slide-deck and student-task-sheet evidence files. The skill treats UbD appropriately as one optional lens among several rather than the default structure, and ACARA's own sequencing guidance is a curriculum-authority resource rather than a research study — it describes recommended practice, not an evaluated intervention. Both are reasonable and commonly-cited sources for this kind of planning guidance, but a reader should not treat either as "proven to improve outcomes" evidence in the same sense as, for example, explicit teaching research.
